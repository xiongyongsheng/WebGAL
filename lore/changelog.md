### 角色塑造原则（永恒世界启发）

**公式：鲜明标签 + 反差**

| 公式 | 含义 |
|---|---|
| **标签** | 一眼记住的单一特征（娇小 / 校花 / 黑客 / 富二代 / 健身狂） |
| **反差** | 第二眼惊喜（恋爱菜鸟 / 宅 / 纹身 / 马甲线） |
| **钩子** | 身份接触机制（摄影师 / 救命 / 任务协同） |

每个女主按此公式塑造，参考《永恒世界》大女儿 = 校花（标签）+ 恋爱菜鸟（反差）+ 摄影师（钩子）。

## **v2.0** · 2026-06-30 17:50

### 重大方向调整 · 末世后宫爽文

用户拍板：**末世只是背景设定，重点是和不同女角色的交互、让她们臣服于主角**（男性向爽文开后宫）。末世 + 丧尸世界观完全保留作为舞台，但叙事重心转向**女主攻略 + 好感度系统**。

### 主角傲天化

| 维度 | 旧（v1.2）| 新（v2.0）|
|---|---|---|
| 性格基调 | 沉重 PTSD 老兵 / 玩世不恭掩盖痛苦 | **魅力型痞帅** / 玩世不恭是风格不是创伤 |
| PTSD | 发作会失能 / 暴怒 / 抑郁底色 | **保留为质感但可控** / 不作主线阴翳 |
| 对女角色 | 礼貌距离 | **主动调侃 / 暧昧 / 推进**（不油腻）|
| Jennna 离开原因 | 因 PTSD 发作不告而别 | **被父亲软禁**（详见 Jennna v2.0）|

### Jennna Maddox · 完整重写（前女友 / 真相线钥匙）

**重大变更**：
- 从"分手/不告而别（情感原因）"改为**"爆发前 1 个月失踪、被父亲软禁（剧情性原因）"**
- 从"PTSD 发作触发离开"改为**"父亲是病毒知情者 + 软禁她以保护"**
- 从"留白现状"改为**"实际被父亲软禁 + 父亲似乎知道将要发生什么"**

**新关键真相**：
- 父亲 = **Lt. Gen. Arthur Maddox 中将**（反对病毒项目的军方高层）
- 父亲软禁 Jennna = "扭曲的保护" → 提前知道病毒泄露 → 紧急保护
- **男主 PTSD 与 Jennna 父亲有关**（间接指挥链 + 父亲干预两人关系）
- Jennna **隐约怀疑**但没证据
- 男主 **完全不知道**

**剧情定位**：**D · 多线混合**（后宫一号 + 真相线钥匙 + 虐恋锚 + 重逢）
