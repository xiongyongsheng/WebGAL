# 剧情结构 · 螺旋上升架构

> **v2.1 架构级变更** · 2026-06-30
>
> 灵感来源：用户推荐的参考作品《永恒世界》的剧情结构。

---

## 一、为什么改

之前 v2.0 走的是 **线性结构**：

```
第 1-6 章  →  Jennna 寻找线
第 7-8 章  →  真相揭露
第 9 章    →  Jennna 重逢
第 10 章+  →  后宫收入 + 父亲线收尾
```

**问题**：
- Jennna 一锤子买卖，9 章后沦为工具人
- 其他女主一旦加入就被卷入主线，没有专属展开
- 父亲线 / Jennna 线 / 共享主线互相挤压，每条线都浅尝辄止
- 不符合用户审美（参考《永恒世界》的多女主 + 螺旋展开）

---

## 二、核心机制：螺旋上升

参考《永恒世界》的剧情结构：**每个女主有专属轮次，共享主线穿插其中，每个女主多次登场**。

```
专属线 A → 专属线 B → 共享主线 ① →
专属线 A 第二轮 → 专属线 C → 共享主线 ② →
专属线 B 第二轮 → 专属线 D → 共享主线 ③ →
大结局
```

### 三大原则

| 原则 | 含义 |
|---|---|
| **多次登场** | 每个女主至少 2-3 轮出现，不是出场一次就走 |
| **专属 + 共享交替** | 专属线深度刻画角色，共享主线推动剧情 + 角色互动 |
| **钩子驱动** | 每个女主有"身份接触钩子"（参考永恒世界的摄影师钩子）—— 不是靠偶遇 / 强行撮合 |

## 四、章回分配（10 章主线 + 1 章大结局）

### 第一阶段：建立期（第 1-3 章）

**第 1 章 · 末日日常 + Jennna 钩子**
- 男主和 Aegis 团队执行日常任务
- 末段：对讲机陌生女声闪过 + 聚居点目击报告（黑皮衣机车女）
- **末段不揭示 Jennna 现状**

**第 2 章 · Jennna 间接线索 + 女主 2 引入**
- 主线任务：某聚居点遇到危机
- Jennna 线索：当地人听过她的名字 / 见过类似的人
- 女主 2 出场：战地医护兵，第一次登场（救援伤员）

**第 3 章 · Jennna 直接线索 + 女主 2 深入**
- 男主和女主 2 协同任务
- Jennna 线索："一个月前，有军方的人带走了一个女子"
- 男主决定追寻 → 队长 Marcus 反对 → 团队冲突
- **女主 2 钩子触发**（受伤被她救 → 关系初步建立）

### 第二阶段：真相期（第 4-6 章 = 共享主线 ①）

**第 4 章 · 父亲势力浮现**
- 男主追踪 Jennna → 接近父亲势力范围
- 父亲信息第一次浮出（军方高层 / 反对病毒项目 / 神秘基地）
- 女主 3 / 女主 4 可选引入

**第 5 章 · 接近真相**
- 男主和女主 2 / 女主 3 协同深入父亲势力范围
- 第一次接触父亲部下 → 战斗 / 情报
- 女主 2 / 女主 3 专属互动

**第 6 章 · 真相大揭露**
- 男主潜入父亲软禁设施
- 父亲会面 → 自报身份 → 男主震惊
- **真相关键全揭露**：父亲 = Lt. Gen. Arthur Maddox / 反对病毒项目 / 软禁 Jennna / 男主 PTSD 与他有关
- Jennna 出现 → 看到父亲和男主对峙 → 复杂情感
- **她第一次看到男主脆弱**

### 第三阶段：重逢期（第 7-9 章）

**第 7 章 · 重逢 + 情感重建**
- 救出 Jennna → 第一次对话（"你瘦了" / "你老了"）
- 通过细节慢慢靠近：黑胶唱片 / 哈雷机车 / JT 纹身 / 素银戒指
- **不直接和好**——保留痞帅张力
- **女主 5（科学家）可在此章引入**：父亲线延伸 → 病毒真相

**第 8 章 · Jennna 专属轮次 ①**
- Jennna 加入队伍 → 和男主协同任务
- 父亲线延伸：父亲势力余孽 / 报复 / 真相后续
- **Jennna 与其他女主的第一次正式碰面**（情敌？姐妹？）
- 关系确立场景

**第 9 章 · 共享主线 ② + Jennna 第二轮**
- 病毒新一波爆发 / 外部威胁 / 政治博弈
- Jennna 作为行动搭档，和女主 2 / 女主 3 协同战斗
- **共享主线把后宫首次串起来**（真正"团队"感）

### 第四阶段：收网期（第 10 章 + 大结局）

**第 10 章 · Jennna 专属轮次 ② + 父亲线收尾**
- 父亲线最终对决：父亲态度转变 / 牺牲救 Jennna（推荐走向 B）
- Jennna 情感线完整收束
- 后宫格局成型

**大结局 · 共享主线 ③**
- 最终危机（病毒 / 外部势力 / 父亲余孽）
- **所有女主 + 男主 + Aegis 团队协同**
- Jennna = 后宫之首（其他女主默认"大姐"地位）
- 多结局分支（按用户偏好可加：圆满 / 留白 / 后宫线 / 单女主线）

## 六、钩子设计原则（抄永恒世界）

每个女主必须有 **"身份接触钩子"** —— 一个持续、合理、不靠偶遇的接触机制。

| 钩子类型 | 示例 |
|---|---|
| **救命 / 被救** | 女主 2（男主受伤被她救）|
| **任务协同** | 女主 3（物资任务 / 聚居点合作）|
| **交易 / 利益** | 女主 4（黑市情报交易）|
| **真相线交叉** | 女主 5（父亲线延伸，CDC 前研究员）|
| **专业身份** | 女主 6（摄影师，跟随拍摄）|

**绝不靠偶遇**——这是《永恒世界》大女儿最聪明的设计。

---

## 七、与永恒世界的差异

| 维度 | 永恒世界 | 我们的项目 |
|---|---|---|
| 推进机制 | 纯分支选择 | **分支 + 好感度阈值 + RPG 成分**（用户原话） |
| 节奏 | 较长 / 多周目 | 单线推进，节奏可调 |
| 战斗 | 轻 / 文字描述 | 中度战斗 + 资源管理 |
| 后宫展开 | 每个女主有专属完整故事 | **同结构 + 螺旋** |
| 反差 + 标签塑造 | 强 | **强（已纳入角色塑造模板）** |

**结论**：抄永恒世界的 **结构 + 塑造原则**，机制保持自己的特色。
