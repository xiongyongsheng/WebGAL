### 🟡 P1 · 主角视角

- **单一固定视角**（玩家 = 主角，玩家代入感强）⭐WebGAL 默认
- 多角色切换（每个角色视角一段，可玩性高但制作成本翻倍）
- 无固定主角（群像剧本，叙事更接近 RPG 而非 Gal）

### 🟢 P2 · 结局倾向

- 多结局（WebGAL 长项）
- 单固定结局（叙事更纯）
- 开放式结局（玩家自己解读）

## 工作守则

- **冲突优先**：人物 / 势力 / 资源三向冲突，给玩家真正的"难选"
- **设定服务于互动**：不是写小说，是**给玩家制造有意义的选择**
- **一致性**：任何设定要写到 `worldbuilding.md` / `characters.md`，不在散落聊天里
- **可回溯**：重大改动要写到 `changelog.md`
