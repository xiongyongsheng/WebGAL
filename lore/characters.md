### USMC 部队设定 ✅ v1

- **军种**：**美国海军陆战队 USMC**
- **单位倾向**：**Force Recon**（海军陆战队特种侦察单位）或 **MARSOC**（海军陆战队特种作战司令部）—— 两者都是 USMC 精锐
- **退役前军衔**：**Staff Sergeant 参谋中士** 或 **Gunnery Sergeant 枪炮军士长**（6-8 年服役）
- **部署经验**：中东（伊拉克/阿富汗）+ 部分亚太
- **退役时间**：约 24 岁

### 心理状态

- **PTSD**：轻微，已治疗，**巨大爆炸声仍会触发**
- **触发症状**（待你具体化）：
  - 闪回 / 震颤 / 暂时失能 / 暴怒 / 退缩？
  - 概率触发，还是场景必发？
- **应对机制**：
  - 靠训练压制（**有极限**）
  - 队友是关键稳定因素
  - 死侍式幽默作为情绪出口

### 性格 ⭐ 关键锚点

**参考漫威死侍"做基因治疗前后"的区别**——

| 死侍特征 | 主角对应表现 |
|---|---|
| 嘴炮 / 自嘲 | 用黑色幽默应对创伤（**不是真的疯，是防御机制**）|
| 玩世不恭 | 不装英雄、不端架子、降低自己期望 |
| 冷漠外表 | **实际很在意身边的人**（要藏好）|
| 极强的战斗力 | 特种兵底子 + 战术素养 |
| "我不想当英雄" | "我只是想活着 / 完成今天的活 / 把工资结了" |
| 偶尔真情流露 | 在某些场景下**短暂露出真性情**（不长时间）|

**不要的**：
- 死侍的"打破第四面墙"（不要真的跟玩家说话）
- 死侍的过度污言秽语（保持写实质感，不做喜剧）
- 死侍的过度自恋（主角应该是**自嘲**，不是**自恋**）

**英文腔调建议**：
- 主角说话节奏偏**快、懒、有停顿**——典型的"靠嘴皮子应对世界"
- 关键词会用缩写、俚语（"Roger"、"Copy"、"On me"）
- 真情流露时反而**字少、停顿长**——和嘴炮形成对比

### 前女友（重要故事钩子）✅ 现状留白

- **国籍**：美国人
- **职业**：模特
- **外貌**：用户描述为"性感"（具体特征待你定）
- **关系**：退役前中期交往（约 1.5-2 年）
- **离开原因**：**或许**因为 PTSD 症状发作（**用户留了余地**）
- **离开时间**：退役后约 3-4 个月
- **现状**：✅ **用户明确"先留白"**
  - 候选设定（**等用户日后决定再启用**）：
    - **失踪**（下落不明，是剧情推动力）
    - **死亡**（早期确认，给主角永久创伤）
    - **变成丧尸**（最戏剧性，**但要注意不要冒犯玩家**）
    - **在某聚居点活着**（重逢线）
    - **已婚他人**（情感深化）
  - **设计意图**：现状留白 = 第一章只能**间接暗示**（照片、回忆、对讲机里偶然听到的消息），**玩家推进剧情时逐步揭示**

### 战斗风格

- **战术素养高**（特种兵底子）
- **冷静判断**（不冲动，**但有触发点会失控**）
- **优先解救人质 / 平民**（道德锚点）
- **不滥用暴力**，但必要时**绝不手软**
- **PSTD 触发时的战斗** vs **正常战斗**应有戏剧对比**

### 主角的"难选"轴

1. **信任**：要不要对队友打开心扉？
2. **底线**：为了弹药 / 食物愿不愿意"脏手"？
3. **牺牲**：救一个同伴 vs 完成任务的资源
4. **真相**：要不要追寻前女友的下落？（可能引出危险）
5. **派系**：Aegis 公司利益 vs 自己的判断
6. **新关系**：有没有可能在废土里遇到新的人？

## 关键 NPC（草案 · v1.2）

### NPC-1 · 队长（战友 + 上司）— **必须**

- **与主角关系**：同一部队战友、后介绍主角入 Aegis、现在的上司 + 队长
- **年龄**：30-32（比主角大 2-4 岁）
- **性格**：稳重、忠诚、有点父兄感、但也有自己的秘密
- **战斗能力**：主角同级或更高
- **钩子**：
  - 主角信任他 / 他信任主角
  - 灾难初期他做了什么决定？（聚居点 / 撤离 / 留守？）
  - 后期可能因某个决定和主角产生冲突
  - **他自己也有家庭**（妻子 / 孩子 / 父母？灾难中怎么样了？）
- **命名建议**（待你定）：**我的默认建议"Marcus Cole"**——简洁、军人感、有兄弟情
- **与主角的化学反应**：
  - 他是主角"理性"的锚
  - 主角 PTSD 发作时他怎么处理？
  - 他会不会**牺牲自己**救主角？（经典但要避免套路）

### NPC-2 · 老兵（同事）— **建议**

- **年龄**：50 岁左右
- **背景**：战前是 Aegis 资深安保员，**参加过伊拉克 / 阿富汗相关私人军事承包商**（黑水风格但避开现实名）
- **性格**：**嘴毒但心善**、保守、不相信新想法、**特别照顾主角**（把主角当半个儿子看）
- **战斗**：经验丰富、枪法准、但体力下滑
- **钩子**：
  - 平时爱讲战场故事，**部分是真的，部分是吹的**
  - 灾难中他**失去了什么**？（老婆 / 战友 / 徒弟）
  - 可能在某个时刻**撑不住**——身心俱疲
- **命名建议**：**"Ray 'Pops' Donovan"**——"Pops"是公司里大家叫他的外号

### NPC-3 · 新人（同事）— **建议**

- **年龄**：23 岁
- **背景**：战前刚入职 Aegis 半年的新人
- **性格**：**热血、爱闯祸、不怕死**（但死过一次后开始怕了）、**管主角叫"哥"**
- **战斗**：体能好、枪法差、**靠主角带**
- **钩子**：
  - 灾难初期**他在哪**？他是靠什么活下来的？
  - 可能因为**一次任务的失败**而陷入低谷
  - **感情线**（如果玩家想推动）：他喜欢公司里的某个人 / 聚居点里的某个人
- **命名建议**：**"Danny 'Kid' Reyes"**——拉丁裔、年轻人

### NPC-4 · 技术员（同事）— **建议**

- **年龄**：28 岁
- **背景**：Aegis 的**前 IT / 通讯专家**，战前负责车队和通讯系统维护
- **性格**：**宅、话少、但关键时刻靠得住**、**战前是远程办公的死宅**
- **专长**：车辆维修、无人机操作、电子破解、监听对讲机频道
- **钩子**：
  - **从来没杀过人**——第一次可能要主角陪着
  - 灾难中**他的家人**在哪？（是否还活着？是个谜）
  - 可能在某次任务中**被招募到更大的组织**（剧情转折）
- **命名建议**：**"Sam Cho"**——华裔技术员，**和主角有"亚裔脸"识别上的微妙联系**（不是亲近，是文化身份认同）

### NPC-5 · 聚居点关键人物 — **建议**

候选：
- **军方代表**（外部权威，**可能是病毒真相线的入口**）
- **聚居点"市长"**（民间领袖，**可能是腐败的也可能是正直的**）
- **黑市商人**（物资交易，**信息灵通**）

### NPC-6 · 散居幸存者（含前女友相关）— **可选**

- 前女友本人（如果选择重逢线 / 死亡线 / 失踪线）
- 散居幸存者家庭（道德抉择锚）
- 神秘幸存者（自带秘密）

### NPC-7 · 反派 — **必须**

候选：
- **暴徒头目**（有魅力的反派，不是疯子）
- **军方反派**（聚居点内部的腐败）
- **神秘组织代表**（病毒真相相关，**可能是第一幕后的大 BOSS**）
