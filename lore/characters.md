### 心理状态

- **PTSD**：轻微，已治疗，**巨大爆炸声仍会触发**
- **触发症状**（待你具体化）：
  - 闪回 / 震颤 / 暂时失能 / 暴怒 / 退缩？
  - 概率触发，还是场景必发？
- **应对机制**：
  - 靠训练压制（**有极限**）
  - 队友是关键稳定因素
  - 死侍式幽默作为情绪出口

### 性格 ⭐ 关键锚点

**参考漫威死侍"做基因治疗前后"的区别**——

| 死侍特征 | 主角对应表现 |
|---|---|
| 嘴炮 / 自嘲 | 用黑色幽默应对创伤（**不是真的疯，是防御机制**）|
| 玩世不恭 | 不装英雄、不端架子、降低自己期望 |
| 冷漠外表 | **实际很在意身边的人**（要藏好）|
| 极强的战斗力 | 特种兵底子 + 战术素养 |
| "我不想当英雄" | "我只是想活着 / 完成今天的活 / 把工资结了" |
| 偶尔真情流露 | 在某些场景下**短暂露出真性情**（不长时间）|

**不要的**：
- 死侍的"打破第四面墙"（不要真的跟玩家说话）
- 死侍的过度污言秽语（保持写实质感，不做喜剧）
- 死侍的过度自恋（主角应该是**自嘲**，不是**自恋**）

### 前女友（重要故事钩子）

- 姓名：待定
- 职业：模特
- 外貌：用户描述为"性感"（具体特征待你定）
- 关系：退役前交往
- 离开原因：**或许**因为 PTSD 症状发作（**用户留了余地**）
- 现状：未知
  - 候选设定：
    - **失踪**（下落不明，是剧情推动力）
    - **死亡**（早期确认，给主角永久创伤）
    - **变成丧尸**（最戏剧性，**但要注意不要冒犯玩家**）
    - **在某聚居点活着**（重逢线）
    - **已婚他人**（情感深化）
  - 这是**第一章或后续章节的核心情感驱动力**

### 战斗风格

- **战术素养高**（特种兵底子）
- **冷静判断**（不冲动，**但有触发点会失控**）
- **优先解救人质 / 平民**（道德锚点）
- **不滥用暴力**，但必要时**绝不手软**
- **PSTD 触发时的战斗** vs **正常战斗**应有戏剧对比

### 主角的"难选"轴

1. **信任**：要不要对队友打开心扉？
2. **底线**：为了弹药 / 食物愿不愿意"脏手"？
3. **牺牲**：救一个同伴 vs 完成任务的资源
4. **真相**：要不要追寻前女友的下落？（可能引出危险）

## 关键 NPC（草案 · v1 · 全部待补）

### NPC-1 · 队长（战友 + 上司）— **必须**

- **与主角关系**：同一部队战友、后介绍主角入安保公司、现在的上司 + 队长
- **年龄**：30-32（比主角大 2-4 岁）
- **性格**：稳重、忠诚、有点父兄感、但也有自己的秘密
- **战斗能力**：主角同级或更高
- **钩子**：
  - 主角信任他 / 他信任主角
  - 灾难初期他做了什么决定？（聚居点 / 撤离 / 留守？）
  - 后期可能因某个决定和主角产生冲突
  - **他自己也有家庭**（妻子 / 孩子 / 父母？灾难中怎么样了？）
- **命名建议**：待你定
- **与主角的化学反应**：
  - 他是主角"理性"的锚
  - 主角 PTSD 发作时他怎么处理？
  - 他会不会**牺牲自己**救主角？（经典但要避免套路）

### NPC-2-4 · 安保公司同事（3 个）— **建议**

每人是不同原型：
- **老兵型**：比主角年长、经验足、保守
- **新人型**：比主角年轻、热血、爱闯祸
- **技术人员型**：车辆 / 通讯 / 黑客专长

### NPC-5 · 聚居点关键人物 — **建议**

候选：
- 军方代表（外部权威）
- 聚居点"市长"（民间领袖）
- 黑市商人（物资交易）

### NPC-6 · 散居幸存者（含前女友相关）— **可选**

- 前女友本人（如果选择重逢线）
- 散居幸存者家庭（道德抉择锚）
- 神秘幸存者（自带秘密）

### NPC-7 · 反派 — **必须**

候选：
- **暴徒头目**（有魅力的反派，不是疯子）
- **军方反派**（聚居点内部的腐败）
- **神秘组织代表**（病毒 / 实验真相相关）
