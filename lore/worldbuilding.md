# 背景设定草案 v1.1

> **v0 → v1 重大变更**：从"灾难后 30 年"改为"丧尸爆发不到一年"。现代城市基础大部分还在，但快速崩坏。
>
> **v1 → v1.1 更新**：补 4 个 P0 决策——伤口传染 / 多种丧尸（参考《消逝的光芒》）/ 虚构城市 / 第一章时间点 = "现在"（爆发 6 个月后）。其余设定待补。

---

## 1. 题材调性 ✅ 已确认

**写实城市废土 + 丧尸题材**

参考作品：
- 《最后生还者》（情感内核 + 真实危机感）
- 《行尸走肉》（人 vs 人 > 人 vs 丧尸）
- 《惊变 28 天》（现代都市快速崩坏）
- 《僵尸世界大战》（大规模感染 / 恐慌）

**关键调性**：
- 写实灰冷色调
- 主角不是英雄，只是**幸存者**
- 暴力作为工具，不是审美
- "活下去"是核心动力

---

## 2. 时间框架 ✅ 重大调整

**丧尸爆发不到一年**（不是灾难后 30 年）

```
T-6月   主角退役特种兵、入职私人安保公司
T-0     丧尸爆发（原因待定）
T-0~3月 爆发初期：基础设施快速崩坏、军方溃败、聚居点形成
T-3~6月 重组期：聚居点定型、贸易形成、暴徒兴起
T-6~12月 当前：城市 95% 感染，幸存者分散到各个据点
────────────────── 现在 ──────────────────
```

**第一章时间点** ✅ 已确认：**丧尸爆发 6 个月后**（"现在"）
- 玩家是老手，不是新手教程
- 城市已被丧尸占据 95%
- 聚居点已成型
- 贸易、暴徒、派系都已在运转

**关键差异**（vs v0 假设）：
- **现代城市基础**大部分还在（建筑、车辆、武器）
- 超市、加油站、药房**可能还有存货**（被抢过的除外）
- 电力 / 自来水 / 通讯**时断时续**
- 手机没信号，**对讲机**比手机重要
- 道路**可能还有半通**，但桥梁 / 隧道被堵
- **节奏感**和 30 年废墟完全不同：**紧迫、混乱、刚崩**

## 3. 丧尸设定（部分已确认 · v1.1）

### 3.1 感染机制 ✅ 已确认
**伤口传染**——不只是咬伤，**抓伤、划伤等任何造成伤口的方式都能传染**。
- 玩家必须严格避免近战暴露
- 即便成功击杀，带血接触也有二次风险
- 战术选择上：远程 > 近战，"开罐头"成为高风险行为

### 3.2 丧尸种类 ✅ 已确认
**多种丧尸**——具体参考《消逝的光芒》（Dying Light）的分类体系，**细节待补**。
- DL 参考要点（先记方向，**具体哪些种类在游戏里出现待补**）：
  - 多种普通感染者（白天出没，慢游或半速）
  - Volatiles / Bolter 等夜间特殊个体（速度快、致命）
  - 白天相对安全 → 夜间极度危险
  - 翻滚、跳跃、跑酷是核心生存方式
- **待你补**：游戏里实际包含哪些种类、各自行为特征、特殊个体的视觉设计

### 3.3 丧尸行为（具体待补）
- DL 默认是"白天慢游 + 夜间危险"——**沿用还是调整**？
- 是否有"被声音吸引变快"机制？

### 3.4 起源（待补）
- DL 是"哈兰病毒"——**沿用**类似自然病毒 / 改为**人工**（实验事故 / 恐怖袭击） / 其他设定？
- 这个会影响主线剧情的"真相"部分

## 5. 势力（草案）

| 势力 | 定位 | 资源 | 与主角关系 |
|---|---|---|---|
| **私人安保公司**（玩家方） | 有组织、有装备、有指挥链 | 武器库、装甲车、信息 | = 主角所属 |
| **军方 / 政府聚居点** | 半组织化、防御 | 重武器、医疗、电力 | 合作 / 服从 / 反抗 |
| **暴徒** | 暴力掠夺、有组织 | 抢来的物资、武器 | ⚔️ 主要敌对 |
| **散居幸存者** | 孤立、无组织 | 各自生存资源 | 🤝 临时合作 |
| **神秘组织**（可选） | 制造 / 利用疫情 | 病毒样本、解药 | ❓ 真相 |

## 6. 资源与经济

### 资源（按重要性）
1. **弹药**（头等重要，硬通货）
2. **燃油**（车辆 / 发电机）
3. **食物 / 水 / 药品**
4. **武器 / 防具**
5. **通讯设备**（**对讲机**比手机重要）
6. **信息**（丧尸动向、聚居点位置、危险区地图）

### 经济
- **弹药是硬通货**
- 旧货币基本无价值
- 信誉 / 关系 = 资源
- **小型服务贸易**（修车、医疗、烹饪）开始出现

## 8. 演出元素（与 WebGAL 引擎对齐）

### 时间系统
- **时辰面板**：早 / 午 / 晚 / 夜
- 不同时辰触发不同事件：
  - **白天**：聚居点贸易、搜寻
  - **黄昏**：暴徒出没预警
  - **夜晚**：丧尸活跃期、潜入窗口
  - **凌晨**：最危险 / 最佳突围窗口

### 玩家状态（GameVar）
- **体力**：影响战斗、逃跑判定
- **伤病**：影响后续行动
- **弹药**：影响战斗策略
- **信誉**：分势力记录
- **同伴状态**：每个 NPC 的存亡 / 关系 / PTSD 状态
- **战力评估**（特种兵高、安保员中、幸存者低）

### 战斗系统
- **基于选择 + 骰子**（不靠玩家操作）
- 战术选择 > 蛮力
- **音效/演出**强化紧张感
- **丧尸音效库**（嘶吼、撕咬、爬行、特殊个体）
