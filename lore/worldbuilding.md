>

>
> **v1.1 → v1.2 更新**：补 5 个 P1 决策——4 种丧尸敌人定稿（固定属性）/ 起源 = 实验室病毒（参考《生化危机》）/ 白天/夜间沿用 DL / 城市 = 美国虚构一线沿海城市 / 公司 = VIP 护卫定位。

## 2. 时间框架 ✅ 已确认

**丧尸爆发不到一年**（不是灾难后 30 年）

```
T-6月    主角入职私人安保公司（已完成治疗，老部队战友介绍）
T-0      丧尸爆发（实验室病毒泄露，参考《生化危机》）
T-0~1月  爆发初期：城市快速失守、军方溃败、第一批聚居点形成
T-1~3月  扩散期：95% 人口被感染 / 死亡，幸存者向沿海港口/郊区逃难
T-3~6月  重组期：聚居点定型、贸易形成、暴徒兴起
T-6~12月 当前：城市 95% 感染，幸存者分散到各个据点
───────────────── 现在 ──────────────────
```

**第一章时间点** ✅ 已确认：**丧尸爆发 6 个月后**（"现在"）
- 玩家是老手，不是新手教程
- 城市已被丧尸占据 95%
- 聚居点已成型
- 贸易、暴徒、派系都已在运转

**关键差异**（vs 30 年废墟）：
- **现代城市基础**大部分还在（建筑、车辆、武器）
- 超市、加油站、药房**可能还有存货**（被抢过的除外）
- 电力 / 自来水 / 通讯**时断时续**
- 手机没信号，**对讲机**比手机重要
- 道路**可能还有半通**，但桥梁 / 隧道被堵
- **节奏感**和 30 年废墟完全不同：**紧迫、混乱、刚崩**

## 3. 丧尸设定 ✅ v1.2 定稿

### 3.1 感染机制 ✅ 已确认
**伤口传染**——不只是咬伤，**抓伤、划伤等任何造成伤口的方式都能传染**。
- 玩家必须严格避免近战暴露
- 即便成功击杀，带血接触也有二次风险
- 战术选择上：远程 > 近战，"开罐头"成为高风险行为

### 3.2 丧尸种类 ✅ 4 种定稿

**核心原则**：固定属性，**不随玩家等级/装备变化**。每种有明确视觉/声音/行为特征，玩几次就能认。

#### 🟢 游荡者（Wanderer）— 最常见
- **HP**：低（手枪 2-3 发）
- **攻击**：低
- **防御**：无
- **速度**：慢（正常人 40%）
- **行为**：随机游荡、群体聚集、对声音反应迟缓
- **视觉**：原城市居民服装腐烂、皮肤青灰、瞳孔浑浊、拖行步伐
- **声音**：低沉呻吟、偶尔咆哮
- **威胁等级**：⭐ 单独无威胁，群体是新手杀手
- **战术**：安静绕开、爆头、单人清理用消音器

#### 🔴 追逐者（Chaser）— 强化型
- **HP**：中（5-7 发手枪弹）
- **攻击**：中（抓伤可击穿薄防弹衣）
- **防御**：中（肌肉变异，常规子弹不致死必须爆头）
- **速度**：**快**（短距离冲刺可达 30km/h）
- **行为**：发现玩家后锁定、高速追击、**不可长时间奔跑甩开**
- **视觉**：肌肉异常发达、青筋暴起、皮肤紧绷、面部扭曲、爪子长且硬
- **声音**：高频尖叫、撕咬声、急促脚步声
- **威胁等级**：⭐⭐⭐ 城市废墟近战遭遇 = 必逃
- **战术**：拉开距离、引到开阔地、用陷阱/绊索、绝不进楼道

#### ⚫ 防暴者（Rioter）— 重装型
- **HP**：**高**（10+ 发手枪弹）
- **攻击**：高（一次撞击可击倒成年人）
- **防御**：**高**（护甲+肌肉，普通子弹打不穿）
- **速度**：慢（正常人 50%，但冲锋时有惯性伤害）
- **行为**：缓慢接近、抓取、抛掷、蓄力冲撞
- **视觉**：**保留原始装备**——警察穿防暴服、士兵穿作战服、工人穿厚重工装。**头面部已变异**，但身体防护完整
- **声音**：低沉吼叫、沉重脚步声、金属摩擦
- **威胁等级**：⭐⭐⭐ 正面 = 必死，必须绕后
- **战术**：用爆炸物/高穿透弹、攻击关节、火攻引燃、绕后爆头

#### ⚪ 哨兵（Sentinel）— 远距侦测型 ✅ v1.2 新增
- **HP**：**极低**（1 发精确命中即倒）
- **攻击**：无（**单体无近战威胁**）
- **防御**：无
- **速度**：正常走步
- **特殊能力**：**高警觉**——视野广（普通丧尸 2 倍）、听觉敏锐、可远距呼叫同伴
- **行为**：**站岗式**——常出现在据点入口、桥梁两端、关键路口；**静止不动像尸体**，玩家容易误判
- **视觉**：**瘦长**、眼白外翻（视觉强化）、**嘴巴缝合/腐烂消失**（无法嘶吼但可发出哨音）、指节敲击金属表面通讯
- **声音**：**金属敲击声**（最危险的前兆——其他丧尸闻声会从 200m 外赶来）、偶尔高频哨音
- **威胁等级**：⭐（单体）→ ⭐⭐⭐⭐⭐（触发后整片区域崩溃）
- **战术**：**优先发现、必杀、必沉默**——一旦它敲出信号，就是一场 5 分钟的死亡竞赛

> **设计意图**：哨兵是**反潜入核心**。普通玩家以为自己在潜行，哨兵在屋顶静静看着，等玩家路过时敲三下金属管——30 秒后整条街都是 Rioter。**它是 DL 里"Volatile"在本作里的具象化替代品**，但更强调**"安静型威胁"**而非"高速威胁"。

### 3.3 行为系统 ✅ 沿用《消逝的光芒》

**白天**（约 06:00-19:00）
- **Wanderer**：随机游荡、群体聚集
- **Chaser**：少见，多在阴影处
- **Rioter**：固定在原"岗位"附近巡逻
- **Sentinel**：静止观察
- **整体**：玩家可以**潜行 + 战术推进**

**黄昏过渡**（19:00-21:00）
- **风险骤升**：各丧尸开始**向玩家聚拢**
- **Sentinel 敲击频率**提高（生物钟变化）
- **最佳窗口**：潜行据点 / 完成任务撤离

**夜间**（21:00-06:00）
- **Wanderer 狂暴化**：速度快 50%、攻击性翻倍
- **Chaser 大量出动**
- **Rioter 仍在原位**但警觉度提升
- **Sentinel 全部激活**——白天安全路线，**夜间全是死路**
- **整体**：玩家**不应在户外过夜**——必须 2 小时内找到庇护所

**凌晨**（02:00-05:00）
- **最危险 / 也是最佳突围窗口**
- 丧尸活跃但**巡逻路径固定**——高手可利用
- **剧情触发点**（重要任务通常安排在这段时间）

### 3.4 起源 ✅ 实验室病毒（参考《生化危机》）

- **类型**：人工基因工程病毒（具体代号待定）
- **泄露原因**：TBD——可以是：
  - 实验室事故（最朴素）
  - 内部人员故意（阴谋论）
  - 恐怖袭击（国际化）
  - **军方生物武器失控**（最有戏剧张力）
- **真相线**：主角可能逐步发现**自己前女友 / 队长 / 公司**和病毒泄露有关联
- **设计意图**：起源设定是**主线"真相"线**的最终答案，**第一章不揭示**，但埋好所有线索

## 4. 地理设定 ✅ v1.2 定稿

### 4.1 城市定位
- **国家**：美国（✅ 确认）
- **类型**：虚构一线沿海城市
- **风格**：**混合风**——以美国西海岸 / 太平洋西北城市为蓝本（西雅图 / 旧金山 / 洛杉矶混合），但地名、街道、品牌全部虚构
- **主角母语**：**英语**（中美混血，但设定在美方一侧）
- **中文对白**：仅在玩家主动选择、或剧情触发回忆杀/通讯时出现

### 4.2 城市具体设定（我自定 · 你过目）

**建议名（待你拍板）**：
- **Port Asher**（港口城市 + 个人名感）
- **西港（Crescent City）**（加州真有这个名字，避开）
- **New Astoria**（新阿斯托利亚）
- **推荐默认**：**"新港市" / Port Asher**——虚构感强、好记、有"港口"暗示（沿海）

**城市规模**：
- 战前人口 **200-250 万**（典型美国一线）
- 现存幸存者估算 **5-8 万**（分散在 10-15 个聚居点）

**地理特征**：
- **沿海 + 港湾**（码头区是重要场景）
- **跨海大桥**（通往郊区的关键通道，**已被封锁**）
- **老城 / 商业区**（核心废墟区，95% 丧尸）
- **港口工业区**（聚居点主基地，有船可撤离，但船只稀缺）
- **郊区山地**（少数隐蔽聚居点，需要穿越丧尸区才能到达）
- **地下通道**（地铁、地下商场、地下停车场 —— 丧尸密度低但视野差、迷路风险高）

**主角熟悉度**：
- 战前**在 Port Asher 工作了 1.5 年**（安保公司派驻）
- **熟悉核心商业区**（日常巡逻范围）
- **不熟悉**老城/港口地下通道（这部分是探索区）

### 4.3 多语言对白处理
- **默认对白**：英语（用 WebGAL 文本显示）
- **中文**：仅在
  - 主角的回忆杀（家人、前女友的中文片段）
  - 玩家自填名后的反应台词
  - 罕见的华裔 NPC（如果有）

## 6. 资源与经济

### 资源（按重要性）
1. **弹药**（头等重要，硬通货）
2. **燃油**（车辆 / 发电机）
3. **食物 / 水 / 药品**
4. **武器 / 防具**
5. **通讯设备**（**对讲机**比手机重要）
6. **信息**（丧尸动向、聚居点位置、危险区地图）

### 经济
- **弹药是硬通货**
- 旧货币基本无价值
- 信誉 / 关系 = 资源
- **小型服务贸易**（修车、医疗、烹饪）开始出现

## 7. 主角所在公司 ✅ v1.2 定稿

### 7.1 业务定位：VIP 护卫
- **核心业务**：高净值客户贴身保护
- **次要业务**：
  - 重要物资护送
  - 私人聚居点防御
  - 关键人物撤离（向港口方向）
- **不接**：大规模军事行动（那是军方的活）、聚居点治安（民间警察/卫队）
- **设计意图**：VIP 业务让主角"见多识广"——能接触各种聚居点的核心人物，但**也容易被卷入派系斗争**

### 7.2 公司具体设定（我自定 · 你过目）

**建议名（待你拍板）**：
- **"Sentinel Group"**（哨兵集团，**和丧尸重名了**，要避）
- **"Aegis Security Solutions"**（神盾安保方案）
- **"Blackthorn Tactical"**（黑刺战术）
- **"Ironline Protective Services"**（铁线防护服务）
- **推荐默认**：**"Aegis Security Solutions"（神盾安保）**——简洁、战术感、不和丧尸重名

**公司规模**：
- 战前：**45-60 人**（美国中型安保公司）
- 现在：**18-25 人**（一半死在爆发 / 撤离职 / 死亡）

**装备水平**：**战术级**
- 个人装备：战术头盔、III 级防弹衣、模块化战术背心、突击步枪（M4/HK416 风格虚构型号）、手枪、战术刀、夜视仪（数量有限）
- 重装备：**1 辆装甲 SUV**（改装自 Escalade / Suburban 风格）、**1 辆运输卡车**、**1 辆摩托车**（侦察用）
- 基地：港口工业区的一个仓库改造，**2 层、有发电机、医疗区、武器库**
- **不和军方比**：没有装甲车、没有直升机、没有重机枪

## 8. 演出元素（与 WebGAL 引擎对齐）

### 时间系统
- **时辰面板**：早 / 午 / 晚 / 夜
- 不同时辰触发不同事件：
  - **白天**：聚居点贸易、搜寻
  - **黄昏**：暴徒出没预警
  - **夜晚**：丧尸活跃期、潜入窗口
  - **凌晨**：最危险 / 最佳突围窗口

### 玩家状态（GameVar）
- **体力**：影响战斗、逃跑判定
- **伤病**：影响后续行动
- **弹药**：影响战斗策略
- **信誉**：分势力记录
- **同伴状态**：每个 NPC 的存亡 / 关系 / PTSD 状态
- **战力评估**（特种兵高、安保员中、幸存者低）

### 战斗系统
- **基于选择 + 骰子**（不靠玩家操作）
- 战术选择 > 蛮力
- **音效/演出**强化紧张感
- **丧尸音效库**（嘶吼、撕咬、爬行、特殊个体）
  - Wanderer：呻吟 + 拖步
  - Chaser：高频尖叫 + 急促脚步
  - Rioter：低吼 + 重步
  - **Sentinel：金属敲击 + 哨音**（最危险音效）
