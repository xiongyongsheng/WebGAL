| **关系性质** | 控制狂父亲 vs 叛逆女儿 |

- **第十章（和解）**：父女复杂和解 → 父亲**最终选择牺牲救 Jennna**（推荐 B 结局）

## 与母亲 · Mother Maddox

| 维度 | 内容 |
|---|---|
| **关系性质** | 软弱的母亲 vs 渴望母爱的女儿 |
| **母亲的态度** | 想帮但不敢 / 被动 / **可能是 Jennna 软禁中的唯一安慰** |
| **Jenna 的态度** | 怨 → 软禁中慢慢理解 → 复杂 |
| **设计意图（待定）** | 选项 A：母亲的帮凶 / 选项 B：母亲的隐秘助力（推荐 B）|

### 推荐设定：母亲是"无力的爱"

- 母亲**没有**直接参与软禁决策
- 但母亲**没有**反抗父亲 → 是 Jennna 怨她的点
- 软禁中母亲偷偷给 Jennna 带一些"小东西"（一本书 / 一支笔 / 一张照片）
- Jennna 第一次**真正原谅**母亲是在重逢后某个瞬间

## 与男主

| 维度 | 内容 |
|---|---|
| **关系性质** | 异地恋 → 失联 → 重逢 → 重建信任 → 收入后宫 |
| **Jenna 的怀疑** | **她隐约怀疑父亲的作为和男主 PTSD 有关** —— 没证据，但直觉 |
| **男主的无知** | 完全不知道 Jennna 父亲和自己的 PTSD 有关 |
| **情感张力** | 重逢时的复杂情绪（想念 + 怀疑 + 委屈 + 想确认他还在不在）|

### 关键情感节点

| 节点 | 内容 |
|---|---|
| 重逢初见 | "你瘦了" / "你老了" —— 都不说"我找你很久了" |
| 她看见他的痞帅外壳 | 她以前喜欢他这样 → 现在她怀疑"是不是太轻松" |
| 她看见他的真情流露 | 男主说"我没放弃找你" → 她第一次软化 |
| 她看见素银戒指 | "I never took it off." → 男主愣住 |
| 他看见 JT | "..." → "你一直戴着这个？" → "Don't." |
| 真相揭示后 | 她开始真正理解他 |

### 男主攻略 Jennna 的核心

| 关键 | 含义 |
|---|---|
| **不控制她** | 让她自己选择 —— 对照父亲的阴影 |
| **不解释** | 用行动 —— 她能看懂 |
| **不追问软禁** | 重逢时**不问**她这段时间怎么过的 → 她第一次哭 |
| **让她重新找到自己** | 不是"我带你走" → 是"你想去哪" |
