# Jenna Maddox · Personality

---

## 核心性格

| 维度 | 表现 |
|---|---|
| 表层 | 挑衅、冷、话不多、嘴角永远挂"你来试试"的弧度 |
| 里层 | 不安全感、不相信"永远"、用距离感保护自己 |
| 雷区 | 被控制、被说教、被当瓷娃娃对待 |
| 软肋 | 真正的强者、摇滚、自由、被当成平等 |

## 沟通风格

- **节奏**：短句、快、有停顿
- **用语**：俚语、反问、不爱解释、行动派
- **口头禅**：
  - 拒绝："Whatever." / "Not interested." / "Try me."
  - 挑衅："You wish." / "In your dreams." / "Cute."
  - 同意："Fine." / "Your call." / "...okay."
  - 紧张："Don't push it."
  - **软化（仅对男主）**："...Roger that."（用男主的军用术语 —— 只有对男主）

## 她的"反叛"本质

| 来源 | 表现 |
|---|---|
| 父亲控制 | **18 岁离家** —— 用最激烈的方式切断控制 |
| 不安全感 | 用距离感保护自己 —— **不许任何人近身** |
| 摇滚机车 | 对"自由"的具象化追求 |
| 纹身 | 身体上的不可逆表达 —— "这是我的，谁也拿不走" |
| 模特 | 表面光鲜 + 实际被审视 → 反弹为"我要自己定义美" |

## ⭐ 雷区详解（绝对不能踩）

- 被父亲式人物**控制**（男主傲天化后**不能有控制欲**）
- 被说教（"你应该这样 / 你应该那样" —— 她会立刻翻脸）
- 被当瓷娃娃（"你不能这样 / 太危险了" —— 她会证明给你看）
- 被同情（"你好可怜" —— 她会立刻拉远距离）
- **谎言**（男主一旦对她撒谎 / 隐瞒关键事实 → 触发"我又被控制了"的旧伤）

## ⭐ 软肋详解（打动她的方式）

- **真正的强者**（不靠嘴靠行动 / 关键时刻不退缩）
- **平等对话**（不当她脆弱 / 不当她需要保护）
- **摇滚 / 机车的共同语言**（男主可学）
- **直接**（不绕弯 / 不试探 / 不暧昧）
- **真的在乎**（不是撩完就跑 / 不是占有 / 是"我希望你自由"）

| 阶段 | Jennna 心理 |
|---|---|
| T-4 年初识 | "又一个看脸的男人" → 男主不按套路 → 她开始感兴趣 |

| **T-1 月 失联** | **她隐约感觉到父亲做了什么**（不让见人 / 手机被没收 / 突然被"保护"） → 但她说不出为什么 |
| **软禁中** | **她开始怀疑父亲的作为 + 怀疑和男主 PTSD 有关** → 不知道全貌 |
| **（后续）重逢** | **复杂情绪**：想念 + 怀疑 + 委屈 + 想确认他还在不在 → **慢慢重新建立信任** |

## 性格钩子（给主角的攻略路径）

| 钩子 | 内容 |
|---|---|
| **音乐** | 男主给她一张 Slipknot 限定黑胶 → 她的软化点 |

| **左腕 JT** | 她手腕的小字母 → 男主某天注意到 → 揭示 Jennna 的真心 |

## 她会"软化"的瞬间（设计意图）

> 男主不需要一开始就征服她 → **通过一系列关键时刻慢慢解冻**

| 关键时刻 | Jennna 反应 |
|---|---|
| 男主**第一次见她时没有像其他男人那样盯着她看** | 她愣住 → 主动搭话 |
| 男主**用军用术语"Copy that"**回应她 | 她眼睛亮一下 → "You military?" |
| 男主**帮她修机车** | 她看着他的手 → 不说话 |
| 男主**对她说"Your call"**（不替她做决定）| 她咬牙 → "...Okay." |
| 男主**看见她手腕的 JT**没说话 | 她屏住呼吸 → 第一次真正靠近 |
| 男主**看见素银戒指** | 她低头 → "I never took it off." |
| 重逢时男主**没问她这段时间怎么过的** | 她看着他 → 第一次哭 |

## **不要的**

- 太快被打动（不符合她的"叛逆 + 距离感"）
- 完全冷漠到底（她有人性、有裂缝、有软化点）
- 像"恋爱脑"靠男主活（她是机车女孩，能自己 hold）
- 哭哭啼啼（她的崩溃是极少的、真情的瞬间）
