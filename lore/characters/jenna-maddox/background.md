- 父亲试图**控制 Jennna 的一切** —— 交友、职业、恋爱、生活
- 母亲是**沉默的旁观者** —— 不反抗、不帮助
- Jennna 18 岁独立后，**父亲仍然通过关系网暗中监视**她
- **男主与 Jennna 交往**：父亲反对（不是因为他本人不好，而是"不能失去控制"）
- **爆发前 1 个月**：父亲用军事资源**软禁** Jennna

## 父亲软禁的原因（设计意图）

> 用户设定："父亲似乎知道将要发生什么"

**真相候选**（详见 [_secrets.md](_secrets.md) 真相候选章节）：

| 选项 | 父亲的动机 |
|---|---|
| A · 知情者 / 内部人 | 父亲是**军方生物武器项目**的核心成员 → 知道病毒会泄露 → 提前"保护"女儿 |
| B · 反对者 / 异见者 | 父亲**反对**病毒项目 → 提前知道要出事 → 紧急"保护"家人 → 但方式错 |
| C · 阴谋论者 | 父亲不是内部人，但**通过情报提前知道** → 紧急"保护" |
| **D · 混合（推荐）** | 父亲**曾经反对** → 病毒还是泄露 → 提前知道时间 → 紧急保护家人 → 但 Jennna 不知道 → 父女对峙时揭晓 |

**推荐 D** —— 最有戏剧张力：
- 父亲不是纯粹反派（避免扁平化）
- 父亲有"扭曲的爱" —— 他真的在乎女儿
- Jennna 视角：父亲是"控制狂" → 真相揭示后："他是**试图救我的人**？" → 复杂情感
- 主角视角：父亲软禁了 Jennna → 真相揭示后："他是**知道真相但选择隐瞒的人**" → 更深的矛盾

## 男主 PTSD 与父亲的关系（关键真相）

> 用户设定："男主的 PTSD 也和她父亲有关，女主有怀疑是不是和她父亲有关，男主对这些一无所知"

**设计意图**（详见 [_secrets.md](_secrets.md)）：

| 选项 | 父亲与 PTSD 的关联 |
|---|---|
| A · 直接关联 | 男主特种兵时期某次任务，**父亲是任务指挥官** → 任务失败 / 战友死亡 → 男主 PTSD |
| B · 间接关联 | 父亲在军方高层 → 男主某次任务与父亲的部门有关 → 失败原因被掩盖 |
| C · 巧合关联 | 父亲**知道男主有 PTSD** → 反对 Jennna 和"有 PTSD 的军人"交往 → 用权力让男主退役（？） |
| **D · 复合关联（推荐）** | 父亲作为高层**间接导致**了 PTSD 的形成 → **Jennna 是真心爱男主，但父亲"保护"她让她无法靠近** |

**推荐 C+D 复合**：
- 父亲反对 Jennna 和男主交往 → **不是因为"他不够好"，而是因为"他会让 Jennna 卷入危险"**（父亲的扭曲逻辑）
- 父亲用权力让男主退役（?）→ 男主不知道 → **Jennna 隐约怀疑但没证据**
- 真相关键：父亲**早就知道男主** —— 可能是男主服役时的上司 / 间接指挥链

## 心理动机

| Jennna | 父亲 |
|---|---|
| **被父亲控制 → 渴望自由** | **世界末日要来 → 保护女儿** |
| **爱上男主 → 但不知父亲已介入** | **反对他们交往 → 用权力干预** |
| **失联后 → 怀疑父亲做了什么** | **软禁她 → 等"危险过去"再放她** |
| **（后续）→ 真相揭晓 → 复杂情感** | **（后续）→ 对峙 / 牺牲 / 反转** |
