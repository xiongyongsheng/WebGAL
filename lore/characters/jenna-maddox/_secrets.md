# Jenna Maddox · 🔒 Secrets（设计意图档案）

> ⚠️ **这是设计意图文档，不是剧情文本**
> 玩家在剧情中**逐步揭示**这些真相，一次性倒出会破坏张力
> 其他作者 / 协作 AI 应该读这个文件了解全局，但**剧情本身不能这样直接告诉玩家**

---

## 核心真相（设计层）

### 1. 父亲的真实身份

| 项 | 真相 |
|---|---|
| **推荐名字** | **General Arthur Maddox**（阿瑟·马多克斯将军）|
| **推荐军衔** | **Lieutenant General**（中将）|
| **推荐部门** | 国防部 / 联合参谋部 / **生物防御高级顾问** |
| **真实身份** | **反对军方生物武器项目的核心人物** |
| **性格** | 控制欲极强 / 表面严厉 / 内心扭曲的"保护欲" —— **不是纯粹反派** |

### 2. 父亲与病毒的关系

```
父亲是军方高层（中将）→
他反对某个生物武器项目 →
项目被高层强行推进 →
父亲通过情报渠道得知项目即将"泄露" →
他无法阻止泄露 →
他选择"保护家人" →
软禁 Jennna →
预期"危险过去后"再放她 →
结果：病毒全球扩散 → 软禁变成"长期囚禁"
```

### 3. 父亲与男主 PTSD 的关系

| 选项 | 真相 |
|---|---|
| **最推荐** | 男主服役时 → **父亲是间接指挥链**上的高层 → 某次任务的失败 + 战友死亡 + 父亲下令掩盖 → 男主 PTSD → 男主不知道 |
| 备选 1 | 父亲**知道男主有 PTSD** → 反对 Jennna 和"不稳定的军人"交往 → 试图"保护"她 |
| 备选 2 | 复合：父亲既**间接导致 PTSD**，又**事后干预 Jennna 的感情** |

**推荐组合**：备选 1 + 2 复合 —— 既"间接导致 PTSD" + 又"干预两人感情"

### 4. Jennna 的怀疑（她自己知道）

- ✅ 她**隐约感觉**父亲的作为和男主有关
- ✅ 她**怀疑**父亲反对他们交往不是因为"他不够好"
- ✅ 她**不知道**具体真相
- ❌ 她**不知道**父亲是病毒知情者
- ❌ 她**不知道**父亲和男主 PTSD 的关系
- ❌ 她**不知道**父亲"间接指挥链"上的具体角色

### 5. Jennna 的软禁状态

| 项 | 详情 |
|---|---|
| **地点** | 父亲名下的**私人设施**（推荐：北加州山区 / 远离城市）|
| **环境** | 类似高端度假屋被改造 → 有守卫、有监控、但 Jennna 可以自由活动 |
| **通信** | 手机被没收 → **没有对外通讯能力** |
| **父亲态度** | "这是保护你" / 不让她离开 / 但不打她 / 给她看新闻但屏蔽部分内容 |
| **Jennna 心理** | **从愤怒到绝望到压抑** → 她没有崩溃（她很硬），但**很孤独** |
| **第一次出场** | 重逢时 —— 她状态比战前憔悴，但眼神还在 |

## 剧情节奏建议（每章揭示程度）

| 章节 | 揭示程度 |
|---|---|
| 第一章 | 仅"她还活着"的暗示（对讲机女声 / 目击报告）|
| 第二~三章 | "她在某个地方被人控制"（聚居点传言）|
| 第四章 | "是她的父亲"（有人透露）|
| 第五章~六章 | "父亲是军方高层" + "他似乎知道些什么" |
| 第七章 | "父亲是病毒知情者 / 反对者" + **Jennna 见到男主** |
| 第八章 | "父亲和男主 PTSD 有关" → 男主情绪爆发 → Jennna 第一次看见男主的脆弱 |
| 第九章 | 重逢 + 救出 → 情感重建 |
| 第十章+ | 父亲线收尾 + Jennna 入队 |

## 父亲线最终走向（候选）

| 选项 | 结局 |
|---|---|
| A · 反派定 | 父亲是彻底的阴谋家 → 最终对决 → 死亡 / 入狱 |
| **B · 反转化（推荐）** | 父亲最后理解了女儿的幸福 → 放她走 → 后续可能在某个事件中**牺牲救 Jennna** |
| C · 灰色 | 父亲不反不化 → 他有他的道理 → 父女关系永久复杂化 → 不和解 |

**推荐 B 理由**：
- 最有人情味（避免扁平化反派）
- Jennna 情感复杂度最高
- 男主的痞帅 + 真诚能打动父亲
- 给父亲一个"扭曲但真"的救赎线

## 男主 PTSD 真相链（设计意图）

```
T-7~8 年（男主 20-21 岁）
  └─ 男主在 USMC Force Recon / MARSOC 服役
     └─ 某次中东任务（伊拉克 / 阿富汗）
        ├─ 任务指挥链上有一位"高级顾问"
        │  └─ **那位是 Arthur Maddox 中将**（时任准将）
        ├─ 任务失败（情报错误 / 时机错误 / 高级顾问的决策）
        ├─ 队友死亡 / 男主负伤 / 心理创伤
        └─ 任务失败被掩盖 / 男主只知"任务失败"

T-5~6 年（男主 22-24 岁）
  └─ 男主退役 / PTSD 治疗

T-4 年（男主 24 岁 / Jennna 20 岁）
  └─ 恋爱开始
     ├─ Jennna 父亲（Arthur）反对
     ├─ "他是个军人 / 会有 PTSD / 会让你受伤"（扭曲的逻辑）
     └─ Jennna 不听 / 父亲暗中监视

T-2 年（男主 26.5 岁 / Jennna 22 岁）
  └─ 异地（男主在 Port Asher）

T-1 月（爆发前 1 个月）
  └─ Arthur 软禁 Jennna
     ├─ "我知道要出事 / 你不能去找他"
     └─ Jennna 隐约感觉父亲的作为和男主 PTSD 有关 → 但没证据

T-0（爆发）
  └─ 病毒扩散 → 软禁变长期

T+6 月（现在）
  └─ 男主寻找 Jennna → 不知道父亲的真相
```
