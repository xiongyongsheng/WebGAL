## 三、逐章细节

### 第 1 章 · 钩子（仅暗示）

| 时点 | 事件 |
|---|---|
| 开场 | 男主和 Aegis 团队执行任务（物资护送 / 聚居点任务）|
| 中段 | 一次无线电通讯中，**陌生女声闪过**（不是 Jennna，但音色相似）→ 男主一愣 |
| 末段 | 返回基地后，**收到一份聚居点目击报告**："某女子，金发黑眼，跨骑机车，黑皮衣" → **与 Jennna 形象高度吻合** → 男主决定追寻 |

> 末段不直接揭示 Jennna 现状 / 父亲真相 → **保留张力**

---

### 第 2-3 章 · 线索期（间接 → 直接）

**第 2 章**：
- 主线任务：某聚居点遇到危机
- Jennna 间接线索：当地人听过她的名字 / 见过类似的人
- 女主 2 第一次登场（战地医护兵救援伤员）

**第 3 章**：
- 男主和女主 2 协同任务
- Jennna **直接线索**："一个月前，有军方的人带走了一个女子"
- 男主决定追寻 → 队长 Marcus 反对 → 团队冲突 → 共识
- 女主 2 钩子触发（受伤被她救 → 关系初步建立）

---

### 第 4-6 章 · 真相期（共享主线 ①）

**第 4 章 · 父亲势力浮现**：
- 男主追踪 Jennna → 接近父亲势力范围
- 父亲信息第一次浮出（军方高层 / 反对病毒项目 / 神秘基地）
- 女主 3 / 女主 4 可选引入

**第 5 章 · 接近真相**：
- 男主和女主 2 / 女主 3 协同深入父亲势力范围
- 第一次接触父亲部下 → 战斗 / 情报
- 女主 2 / 女主 3 专属互动

**第 6 章 · 真相大揭露**：
- 男主潜入父亲软禁设施
- 父亲会面 → 自报身份（**Lt. Gen. Arthur Maddox 中将**）→ 男主震惊
- **真相关键全揭露**：
  - 父亲 = 反对病毒项目的军方高层
  - 父亲软禁 Jennna = "扭曲的保护" → 提前知道病毒泄露 → 紧急保护
  - **男主 PTSD 与父亲有关**：服役时父亲是间接指挥链 → 某次任务失败 → 男主 PTSD → 父亲事后干预两人关系
- Jennna 出现 → 看到父亲和男主对峙 → 复杂情感
- **她第一次看到男主脆弱**
- 男主对父亲说"你让我失去了一切" → 她愣住

> ⚡ 关键情感节点：这是 Jennna 第一次意识到"原来一切不是偶然"

---

### 第 7 章 · 重逢 + 情感重建（关键章）

| 节点 | 内容 |
|---|---|
| 救出 Jennna | 主角团 vs 父亲势力 → Jennna 获救 |
| 第一次对话 | "你瘦了" / "你老了" / 都不说"我找你很久了" |
| 关系重建 | **不直接和好** → 通过几个细节慢慢靠近 |
| 关键场景 1 | 男主把她的 Slipknot 黑胶给她 → **她软化** |
| 关键场景 2 | 男主把她的哈雷弄回来 → **她彻底软化** |
| 关键场景 3 | 她手腕的 JT 纹身 → 男主注意到 → "你一直戴着这个？" → "Don't." |
| 关键场景 4 | 素银戒指 → 她没解释 → "I never took it off." → 男主真情流露瞬间 |
| **关系确立场景** | 好感度阈值触发 → 留白处理（具体细节由后续剧本填充）|

> 女主 5（科学家）可在此章引入：父亲线延伸 → 病毒真相 → CDC 前研究员身份

## 四、父亲线（核心真相 · 已定稿）

### 身份

| 要素 | 真相 |
|---|---|
| **父亲的军衔** | Lieutenant General Arthur Maddox（阿瑟·马多克斯中将）|
| **父亲的真实身份** | **军方高层 / 反对病毒项目** —— 不是发起人，是反对者 |
| **父亲为什么提前知道** | 他在国防部任职，能接触到"绝密"级别的情报 → 项目泄露前他已知情 |
| **父亲为什么软禁 Jennna** | 他知道要出事 → 紧急"保护" → 但方式扭曲 |
| **父亲与男主 PTSD** | 男主服役时 → **父亲是间接指挥链** → 某次任务失败 → 男主 PTSD → 父亲事后干预两人关系 |

### 最终走向（推荐 B · 已采纳）

| 走向 | 描述 |
|---|---|
| **B · 反转化（推荐 / 已定稿）** | 父亲最终理解了女儿的幸福 → 放她走 → 后续某个关键事件**牺牲救 Jennna** |
| A · 反派定 | 父亲是彻底的阴谋家 → 最终对决 → 死亡 / 入狱 |
| C · 灰色 | 父女关系永久复杂化 → 不和解 |

**B 已定稿** —— 最有人情味 + Jennna 情感复杂度最高 + 男主的痞帅 + 真诚能打动父亲。
