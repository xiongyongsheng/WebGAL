# 主角 · Personality

## 核心性格

| 维度 | 表现 |
|---|---|
| 表面 | 痞帅、嘴炮、玩世不恭、自嘲 |
| 内部 | 见过太多、有责任感、很在意身边的人 |
| 触发点 | 真情流露瞬间（字少、停顿长）|
| 雷区 | 被当英雄、被说教、被同情 |

## 死侍式幽默（参考）

| 死侍特征 | 主角对应 |
|---|---|
| 嘴炮 / 自嘲 | 黑色幽默应对世界 |
| 玩世不恭 | 不装英雄、不端架子 |
| 极强的战斗力 | 特种兵底子 + 战术素养 |
| "我不想当英雄" | "我只是想活着 / 完成今天的活 / 把工资结了" |
| 偶尔真情流露 | 在某些场景**短暂露出真性情**（不长时间）|

## **不要的**

- 打破第四面墙（不要真的跟玩家说话）
- 过度污言秽语（保持写实质感，不做喜剧）
- 过度自恋（应该是**自嘲**，不是**自恋**）

## ⭐ 对女角色的态度（v2.0 新增 · 傲天化核心）

| 维度 | 表现 |
|---|---|
| 主动度 | **会主动调侃、暧昧、推进**——不是被撩型，是会撩型 |
| 分寸感 | 不油腻 / 不强迫 / 不过界 / **会读对方底线** |
| 尊重 | 真正尊重女角色的选择 / 不为爽文而写强迫 |
| 软肋 | 软妹子 / 强女主 / 互补型 / 都能 hold |
| 关键风格 | "I'm not asking. I'm offering." / "Your call, sweetheart." |

### 对女角色的三种模式

| 模式 | 适用角色 | 表现 |
|---|---|---|
| **痞帅调侃** | Jennna / 强女主 | 直接、有来有回、不服输 |
| **温柔护短** | 软妹子 / 受过伤的 | 收敛玩世不恭、变成保护者 |
| **平等对话** | 知识分子 / 科学家 | 不油嘴滑舌、用真诚回应 |

## PTSD 调整（v2.0 重大变更）

| 旧设定（v1.2）| 新设定（v2.0）|
|---|---|
| 巨大爆炸声仍会触发 | **保留** —— 但发作程度弱化 |
| 发作会失能 / 暴怒 | **弱化** —— 可触发但**可控**，短暂震颤后恢复 |
| PTSD 是核心人物深度 | **淡化** —— 保留为人物质感，**不作主线阴翳** |
| 抑郁底色 | **移除** —— 改用"痞帅 + 护短"替代人物深度 |
| Jennna 离开是因 PTSD 发作 | **重写** —— Jennna 离开是因为被父亲软禁（详见 Jennna 档案）|

### 保留的 PTSD 元素

- ✅ 巨大爆炸声仍可触发（短暂）
- ✅ 训练压制（有极限，但大多数时候够用）
- ✅ 队友是稳定因素
- ✅ 死侍式幽默是情绪出口
- ✅ **新增**：在女角色面前稳定情绪 → 转化成"护短"的动力

## 心理成长弧线

| 章节阶段 | 主角状态 |
|---|---|
| 第一章 | 玩世不恭 + 痞帅推进 + 偶尔真情流露 |
| 第二~三章 | 任务推进 + 女主互动 + PTSD 偶尔触发 |
| 第四~六章 | 真相线推进 + 主角开始认真 |
| 第七~八章 | 父亲线 + PTSD 真相关联揭示 → **痞帅外壳开始破裂** |
| 第九章 | Jennna 重逢 → **真情流露瞬间** |
| 第十章+ | 主角"完整" → 不再逃避过去 + 后宫建立 |
