# 主角 · Voice

## 说话节奏

| 场景 | 节奏 |
|---|---|
| 日常 | 偏快、懒、有停顿，靠嘴皮子应对世界 |
| 真情流露 | 字少、停顿长——和嘴炮形成对比 |
| 战斗 | 短促命令、清晰 —— "Roger / Copy / On me" |
| 调情 | 不油、有来有回、点到为止 |

## 关键词 / 俚语

| 场景 | 用语 |
|---|---|
| 战斗 | "Roger", "Copy", "On me", "Moving", "Contact left/right" |
| 日常调侃 | "Roger that", "Your call", "Sweetheart", "Darlin'", "Easy" |
| 认真时 | "Listen" / "Look" / "Here's the deal" / "Trust me on this" |

## 调情风格（v2.0 新增）

| 类型 | 台词 |
|---|---|
| 直接型 | "I'm not asking. I'm offering." |
| 退让型 | "Your call, sweetheart." |
| 调侃型 | "You sure you wanna play that game with me?" |
| 认真型 | "I mean it."（停顿）"Every word." |
| 护短型 | "You hurt her, you answer to me." |

## 调侃女角色 · 台词样本（参考）

> ⚠️ 这些是**风格样本**，实际对白要看具体角色和场景调整

```
// 痞帅调侃
"Well, that's not the worst thing I've woken up to."
"You sure you wanna play that game with me, sweetheart?"

// 暧昧推进
"I'm not asking. I'm offering."
"Take your time. I'm not going anywhere."

// 战斗间隙
"You good?"
"Yeah. You?"
"Copy."

// 关键时刻（真情流露）
"...Listen."
(long pause)
"I'm not gonna let that happen. Not again."

// 护短瞬间
"You hurt her, you answer to me."
"Step. Back."
```

## 战斗语音

```
"On me!"
"Moving!"
"Contact left! Two, maybe three!"
"Suppress! I'm flanking!"
"Clear!"
"Reloading!"
```

## **不要的**

- 过度粗口（保持写实质感）
- 调侃女性身体部位的低俗梗（**绝对避免**）
- 油腻情话（要痞帅不是土味）
- 频繁的"babe" / "honey"（要分角色用）
