# 主角 · Plot Arc

## 角色主线

| 弧线 | 内容 |
|---|---|
| **生存线** | 带领 Aegis 团队在末世中活下来 → 任务、战斗、补给 |
| **女主线** | 与多位女主建立关系 → 调情、暧昧、信任、最终收入后宫 |
| **真相线** | 追寻 Jennna 的下落 → 揭开病毒真相 → 发现其父是关键人物 |
| **PTSD 线**（v2.0 弱化）| 偶尔触发但可控 → 不作主线阴翳，作人物质感 |
| **成长线** | 玩世不恭外壳 → 在 Jennna 重逢时真情流露 → 内心"完整" |
