## 📁 目录约定

```
<角色 ID>/
├── profile.md        # 主档案（基础信息 + 性格速览 + 剧情定位）
├── appearance.md     # 外貌 + AI 绘图 prompt
├── personality.md    # 性格详解 + 雷区/软肋/攻略路径
├── background.md     # 背景故事 / 家庭 / 时间线
├── voice.md          # 说话风格 / 台词样本
├── plot-arc.md       # 剧情弧线 / 出场计划 / 关键场景
├── relationships.md  # 关系网（仅主要角色需要）
├── _secrets.md       # 🔒 设计意图档案（仅需要时建立）
└── assets/           # 参考图 / 概念图 / 立绘
    ├── ref-*.png     # 参考图（命名按内容/角度）
    ├── concept-*.png # 概念图（场景、氛围）
    └── portrait-*.png # 立绘（最终角色图）
```

## 角色 ID 命名约定

- 使用小写英文 + 连字符
- 例：`jenna-maddox` / `marcus-cole` / `protagonist`
- 避免缩写（除非广为人知）
