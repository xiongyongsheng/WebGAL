; ====================================================================
; 角色系统（2026-06-09 重构）
;
; 之前：所有角色数据硬编码在 setVar:scavenge_characters=[...] 里
;   → 角色多 → 存档大
;   → 加新角色要改场景脚本
;   → 露西放在初始存档里（不符合剧情逻辑）
;
; 现在：
; - 角色基础数据存到 characterRoster.ts（代码侧，单一真相源）
; - 存档只存"已获得的角色 ID 列表"：scavenge_character_ids
; - CharacterRosterManager 监听这个 ID 列表 → 从 templates 构建完整角色
;   → 自动写入 scavenge_characters（运行时缓存，给 UI 读）
;
; 2026-06-09 改：scavenge_main.txt 不再硬编码 character_ids
;   → 避免从剧情回到 scavenge_main 时把"剧情获得的新角色"覆盖回 [player_1]
;   → CharacterRosterManager 兜底逻辑处理：
;     - 首次 mount：character_ids 为空 → 写入 [player_1]（默认值）
;     - 剧情已获得角色：character_ids 是 [player_1, lucy] → 跳过兜底，保留剧情结果
; ====================================================================
;（不在这里 setVar:scavenge_character_ids，由 CharacterRosterManager 兜底）

;   - 没红点 → 走 jumpScene 进 safehouse
