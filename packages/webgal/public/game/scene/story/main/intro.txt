; 关闭拾荒 UI（让玩家专注剧情）

setVar:show_scavenge_time_control=false;

setVar:scavenge_show_character_list=false;
setVar:scavenge_show_menu=true;

; 主角视角的内心独白（无角色立绘，用普通 say）
你缓缓睁开眼睛。周围是破败的天花板，锈迹斑斑的水管发出滴水声。;
空气中弥漫着霉味和消毒水混合的气息。;
你不知道自己是怎么来到这里的。;

窗外是灰蒙蒙的天空。远处的城市轮廓残破不堪。街道上几乎看不到行人。;

; 门被推开的声音
咔哒——门被推开了。;

; 露西出场
露西:你醒了。;
露西:我叫露西，就住在隔壁。前几天看到你被扔在这里……就顺手照看了下。;
露西:外面已经没多少活着的人了，物资也越来越难找。;
露西:……你愿意和我一起吗？两个人总比一个人好。;

; 主角内心
你看着眼前这个瘦削但眼神坚定的女孩，点了点头。;

; 把露西加入队伍（触发 characterRoster manager）
; 2026-06-09 改：商人维克斯是中立角色（faction='neutral'），由 scavenge_neutral_ids 管理
;   → 不放在队伍花名册里。队伍只有 ally 角色（player_1 + 露西）
; 2026-06-21 改：清 _last_built_character_ids cache，确保 CharacterRosterManager 一定重**新**构**建**
;   - 防止玩家从剧情回到 scavenge_main 后，因为 cache 命中漏构 lucy
setVar:_last_built_character_ids=;
setVar:scavenge_character_ids=[player_1,lucy];

; 打开拾荒 UI
setVar:show_scavenge_map=true;
setVar:show_scavenge_time_control=true;
